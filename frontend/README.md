# UniTransit Frontend

Interactive commuter-focused web application built with React, Leaflet, and WebSockets.

## Key Views
- **Live Map**: Real-time vehicle positions with smooth marker animation, routes polyline rendering, and stop clusters.
- **Routes & Schedules**: Route exploration, stop sequences, and next arrival estimates.
- **Stops & Arrivals**: Station-centric views and live ETA boards.
- **Service Alerts**: Push notifications and alert banners for route delays and disruptions.
- **Vehicle Inspector**: Telemetry drilldown (speed, heading, occupancy, telemetry logs).
