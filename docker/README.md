# Docker Images & Containerization

Production-ready multi-stage Dockerfiles and Nginx reverse proxy configurations.

## Dockerfiles
- `Dockerfile.backend`: Multi-stage Python 3.11 image with GDAL/GEOS for PostGIS.
- `Dockerfile.frontend`: Multi-stage Node build with lightweight Nginx static web server.
- `Dockerfile.worker`: Optimized headless Python runner for telemetry consumption.
- `Dockerfile.simulator`: Standalone vehicle simulator image.
